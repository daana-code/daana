# Daana

Daana is a platform that turns raw operational data into a business representation that is ready for BI. This repository is where the Daana CLI is published: release binaries, install instructions and checksums.

Downloads are on the [Releases](https://github.com/daana-code/daana/releases) page. There is no release there yet; the first one will appear when it is published.

- Website: https://daana.dev
- Documentation: https://docs.daana.dev
